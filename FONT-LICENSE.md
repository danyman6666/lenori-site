# Typeface

The display typeface is **Fraunces**, the same variable font the Lenori iOS
app uses for its headlines. It is served from this domain
(`/fonts/Fraunces.ttf`) rather than from a font CDN, so loading a page on
lenoriapp.com contacts no third party.

## Licence

Fraunces is licensed under the **SIL Open Font License, Version 1.1**. The
complete, unmodified licence text is in **[`fonts/OFL.txt`](fonts/OFL.txt)**,
obtained from the upstream project:

<https://github.com/undercasetype/Fraunces>

### Copyright notices

The licence file as published upstream carries:

> Copyright 2018 The Fraunces Project Authors (https://github.com/undercasetype/Fraunces)

The font binary bundled here is Fraunces **Version 1.000**, and the copyright
notice embedded in that file reads:

> Copyright 2020 The Fraunces Project Authors (github.com/undercasetype/Fraunces)

Both are recorded because OFL §2 requires each distributed copy to carry "the
above copyright notice and this license", and the notice that travels with the
binary is the one inside it. Neither has been edited.

### Reserved Font Name

Fraunces declares **no** Reserved Font Name — its copyright line carries no
"with Reserved Font Name" clause. Nothing here renames or modifies the font,
so OFL §3 does not apply.

### What the licence permits here

OFL §2 expressly allows the font to be bundled and redistributed with
software, including commercially, provided the copyright notice and licence
travel with it. OFL §1 forbids selling the font by itself, which this site
does not do. The font is served as-is, unmodified.
