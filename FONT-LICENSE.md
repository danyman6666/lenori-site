# Typeface

The display typeface is **Fraunces**, the same variable font the Lenori iOS
app registers and draws its headlines with. It is served from this domain
(`/fonts/Fraunces.ttf`) rather than from a font CDN, so loading a page on
lenoriapp.com contacts no third party.

Fraunces is published under the **SIL Open Font License, Version 1.1**.
Upstream project: <https://github.com/undercasetype/Fraunces>

## Before launch

Copy the upstream `OFL.txt` into this repository verbatim, including its
copyright line and any Reserved Font Name, and link it from here. The OFL
requires the licence to travel with the font, and the exact copyright
statement must come from upstream rather than be paraphrased.

This file is a placeholder for that step, not a substitute for it.
