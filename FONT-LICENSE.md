# Typeface

The display typeface is **Fraunces**, the same variable font the Lenori iOS
app uses for its headlines. It is served from this domain
(`/fonts/Fraunces.ttf`) rather than from a font CDN, so loading a page on
lenoriapp.com contacts no third party.

Fraunces is published by its authors under the **SIL Open Font License,
Version 1.1**, which permits redistribution and embedding, including in
commercial work, provided the font is distributed under the same licence and
is not sold on its own.

Upstream project and the authoritative licence text:
<https://github.com/undercasetype/Fraunces>

The OFL requires its licence text to travel with the font. Before any
redistribution of the font file outside this website, copy the upstream
`OFL.txt` into this repository verbatim — including its copyright line and
any Reserved Font Name — and link it from here.
